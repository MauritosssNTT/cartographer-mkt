# Knowledge Market domain glossary

This glossary defines product language only. It intentionally does not prescribe implementation
details.

| Term | Meaning |
| --- | --- |
| Knowledge Base (KB) | A versioned capability pack made available through the marketplace. It can contain knowledge sources and agent capabilities. |
| Capability pack | The marketplace presentation of a KB and its contents: knowledge, skills, MCP servers, and hooks. |
| Catalogue | The set of KB listings available for discovery in the marketplace. |
| Listing | The marketplace metadata that describes one KB: vendor, version, trust, pricing, quality, contents, sources, and releases. |
| Vendor | The organisation or maintainer that publishes one or more KB listings. |
| Trust level | The provenance classification shown for a listing: Official, Verified, or Community. It is distinct from a market tier. |
| Market tier | The commercial or editorial positioning of a listing: Premium, Professional, or Community. It is distinct from a trust level. |
| Manifest | The machine-readable representation of a listing used by an agent to identify an installable KB package. |
| Install prompt | A user-copyable instruction that tells an AI agent to install a KB from its manifest URL. It is not itself an installation. |
| Publish prompt | A user-copyable instruction that asks an AI agent to guide publication of a KB. It is not itself publication. |
